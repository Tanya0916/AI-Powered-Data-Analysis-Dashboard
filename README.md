# AI-Powered Data Analysis Dashboard

## Objective
Analyze Heart Disease Dataset using data preprocessing, visualization and AI-driven insights.

## Features

- CSV Dataset Import
- Dataset Statistics
- Missing Value Detection
- Data Visualization
- Correlation Heatmap
- AI Generated Insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Dataset

Heart Disease Dataset
Rows: 1025
Columns: 14

## Run Project

pip install -r requirements.txt

streamlit run app.py
